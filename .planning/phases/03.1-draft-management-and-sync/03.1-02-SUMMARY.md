# Phase 03.1 Plan 02: Frontend Wiring for Draft Sync

Added frontend integration connecting the new Draft CRUD API routes to the React UI, enabling real-time editing and deletion of drafts.

## Implementation Details
1. **API Hooks:** Extended `web/src/services/api.ts` with `updateDraft`, `deleteDraft`, and `syncDrafts` mapped strictly to the new endpoints we built.
2. **Draft Actions UI:** Modified the `DraftsPage` layout to include inline controls. Added `Edit2` and `Trash2` icons next to unsent drafts in the list.
3. **Inline Edit View:** Hooked an inline editing view directly into the preview pane logic. If `isEditing` state is active, the preview displays input and textarea tags for live subject and body rewriting.
4. **Manual Sync Trigger:** Included a RefreshCw `Sync` button in the header so the user can manually force the backend to reconcile local EmailLogs with the actual Gmail records.
